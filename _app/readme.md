Há nessa pasta exemplo de aplicações usando o Alcance.
Todas elas dependem de instalar o Alcance via NPM.

Para criar outro exemplo de aplicação, ou atualizar um exemplo existente,
vá na pasta `alc` dê os seguintes comandos:
 - npm run build
 - npm pack

 Copie o arquivo gerado "alc-x.x.x-x.tgz" para a pasta do exemplo desejado e:
  - npm install alc-x.x.x-x.tgz

Suba um servidor web qualquer (pode usar o "Live Server" do VSCode),
navegue até a pasta da aplicação exemplo desejada e veja o resultado.
