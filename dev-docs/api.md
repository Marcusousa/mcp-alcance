# Conceito de API

Tudo o que está na documentação faz parte da API do Alcance.

É um compromisso de entrega feito com os usuários do design system.

Por isso é tão importante que haja uma revisão criteriosa especialmente daquilo que acrescenta ou modifica algo na documentação. A partir do momento que foi ali colocado, um usuário pode começar a usar daquela forma. Uma alteração posterior tem um custo potencial.

## Alfa

Manter algo em "alfa" indica que não assumimos nenhum compromisso com a API. Há liberdade para fazer modificações. Na dúvida, colocar algo novo marcado como "alfa", ou fazer modificações mantendo o componente em "alfa", é uma estratégia segura.
