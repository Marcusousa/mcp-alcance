Esse componente é uma versão antiga de `alc-header`, que foi mantida com o novo nome `alc-header-v1`.

Isso permite que uma aplicação siga usando, provisoriamente, o modelo antigo de header. É necessário usar
o componente `alc-header-v1` onde antes se usava `alc-header`. É uma solução de contorno para que se tenha tempo
para fazer a migração para o novo `alc-header` (recomendado).

O novo componente `alc-header` não é compatível com o antigo.

<Unstyled>

---

O componente `header` deve ser utilizado em todas as páginas do sistema. Contém os elementos que
naturalmente se repetem em todas as páginas, como a identificação do ambiente, o nome do sistema etc.
