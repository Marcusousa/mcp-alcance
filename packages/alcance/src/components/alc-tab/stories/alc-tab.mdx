# {Stories.default.name}

O componente `alc-tab` é utilizado para criar o conteúdo de uma aba dentro de um conjunto de abas. Ele deve ser usado em conjunto com o componente `alc-tabs` e os botões de aba `alc-tab-button`.

<Unstyled>
    <alc-alert dismissible="false">
    **Importante**: O `alc-tab` **não funciona isoladamente**. Ele depende da estrutura fornecida pelo `alc-tabs` para controlar a exibição de abas e conteúdos.
    </alc-alert>
</Unstyled>


## Propriedade content-focus
Essa propriedade controla o comportamento do foco ao navegar com a tecla `Tab`.

Quando o foco está no seletor da aba (um `tab-button`), ao pressionar `Tab` há duas possibilidades de foco:
<ul className="list-disc list-inside">
  <li>Para o primeiro elemento focalizável dentro da aba.</li>
  <li>Para a própria aba (o conteúdo como um todo).</li>
</ul>

O `content-focus` determina se o foco deve ir para o primeiro elemento focalizável.

Sua escolha deve ser baseada nesse critério: o primeiro conteúdo significativo dentro da aba é focalizável?

### Como usar content-focus:
<ul className="list-disc list-inside">
  <li>`content-focus="true"`: Use se o primeiro conteúdo significativo da aba for um elemento focalizável, como um campo de formulário, link ou botão.</li>
  <li>`content-focus="false"` (padrão): Use se o primeiro conteúdo significativo **não** for um elemento focalizável, como um parágrafo ou uma imagem sem link.</li>
</ul>

### Exemplos de uso

#### Aba que inicia com um campo de formulário
Se o primeiro item da aba é um campo de formulário (focalizável), defina `content-focus` como `true`.

<CodeExample type="html" highlightedWords={['content-focus','true']}>
{`<alc-tabs>
  <alc-tab-button slot="button" tab="tab-1">ThunderCats</alc-tab-button>
  <alc-tab tab="tab-1" content-focus="true">
    <input type="text" placeholder="Quem é o líder dos ThunderCats?" />
    <button type="submit" class="alc-button">Enviar</button>
  </alc-tab>
</alc-tabs>`}
</CodeExample>

#### Aba com apenas informações textuais
Se a aba não tem elemento focalizável, então a propriedade `content-focus` deve ser `false`.
Como este é o valor padrão, você pode simplesmente omitir a propriedade.

<CodeExample type="html" highlightedWords={['content-focus' ,'false']}>
{`<alc-tabs>
  <alc-tab-button slot="button" tab="tab-1">ThunderCats</alc-tab-button>
  <alc-tab tab="tab-1">
    <p>
      ThunderCats é uma franquia de animação dos anos 1980 sobre guerreiros felinos humanoides
      que fogem do planeta Thundera e lutam contra o vilão Mumm-Ra no Terceiro Mundo.
      Liderados por Lion-O, eles protegem a Espada Justiceira e o Olho de Thundera.
    </p>
  </alc-tab>
</alc-tabs>`}
</CodeExample>

#### Abas com imagem e links
Aqui, a decisão de `content-focus` depende se a imagem é considerada o conteúdo significativo.
<ul className="list-disc list-inside">
  <li>Aba "Introdução": A imagem é decorativa (`alt=""`). O primeiro conteúdo significativo é o link, que é focalizável. Por isso, usamos `content-focus="true"`.</li>
  <li>Aba "Espada": A imagem é significativa (`alt="Espada Justiceira"`), mas não focalizável. O foco não deve "saltar para os links logo em seguida. Por isso, `content-focus="false"`.</li>
</ul>

<CodeExample type="html" highlightedWords={['content-focus' ,'true', 'false']}>
{`<alc-tabs>
  <alc-tab-button slot="button" tab="tab-1">Introdução</alc-tab-button>
  <alc-tab-button slot="button" tab="tab-2">Espada</alc-tab-button>
  <alc-tab tab="tab-1" content-focus="true">
    <img src="decorative-image.jpg" alt="" />
    <ul>
      <li><a href="#" class="alc-link">Link 1</a></li>
      <li><a href="#" class="alc-link">Link 2</a></li>
    </ul>
  </alc-tab>
  <alc-tab tab="tab-2" content-focus="false">
    <img src="decorative-image.jpg" alt="Espada Justiceira" />
    <ul>
      <li><a href="#" class="alc-link">Link 1</a></li>
      <li><a href="#" class="alc-link">Link 2</a></li>
    </ul>
  </alc-tab>
</alc-tabs>`}
</CodeExample>
