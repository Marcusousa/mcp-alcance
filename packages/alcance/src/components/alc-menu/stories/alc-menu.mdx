# {Stories.default.name}

Um menu é utilizado para reunir ações relevantes dentro de um contexto, como uma área da interface, ou uma linha em uma tabela.

Não se confunde com a navegação da aplicação, que utiliza o componente `nav`.

Usualmente, o `menu` é utilizado juntamente com o componente `dropdown`, que é responsável pela exibição do conteúdo sobreposto ao conteúdo da página, associado a um elemento responsável por esse acionamento.
