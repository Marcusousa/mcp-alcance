# {Stories.default.name}
O componente alc-header-notifications serve para exibir notificações no cabeçalho da aplicação. 
Ele é utilizado para informar aos usuários sobre eventos importantes, como novas mensagens, atualizações ou alertas.

Você pode utilizar como botão ou link, dependendo da necessidade do sistema. 
Utilize link quando a notifição for levar o usuário para uma página específica, adicionando a propriedade `variant="link"` 
e atribuindo valor à propriedade `url`.
