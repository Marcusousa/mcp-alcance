## {Stories.ModalInsideForm.name}
Para uma janela modal com formulário, com o botão de submit no slot footer,
uma forma simples de fazer é, no html, deixar a tag `form` envolvendo a tag `alc-modal`.

Dessa forma, mesmo que o componente modal manipule os botões para posicioná-los no footer,
eles continuam contidos no formulário e funcionando adequadamente.

<Canvas of={Stories.ModalInsideForm} sourceState="shown" />
<Controls of={Stories.ModalInsideForm} />

## {Stories.FormInsideModal.name}
Caso a estrutura mostrada no exemplo anterior não atenda às necessidades, e a tag `form`
precise estar contida na tag `alc-modal`, e o botão de submit ainda tenha que estar no footer
da janela modal, essa estrutura pode ser utilizada.


Nesse caso, é necessário:
* definir um id único para o form;
* deixar a área de botões (slot buttons) fora do form;
* usar o <a class='alc-link' href='https://developer.mozilla.org/en-US/docs/Web/HTML/Element/button#form'>atributo form</a> do botão apontando para o id do form.
