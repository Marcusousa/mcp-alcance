## Básico com conteúdo
O `alc-pagination` pode ser usado para paginar qualquer tipo de conteúdo. Ele simplesmente fornece os controles de paginação.

Aqui está um exemplo de uma aplicação típica do componente, com o código mínimo para realizar a paginação visualmente.

## Exemplos Avançados
### Uso no Vue

Note que esse componente possui o recurso de modelo virtual (v-model), que permite
criar um vínculo bidirecional entre uma variável da aplicação e o componente.

O `v-model` refere-se ao atributo `current-page` do componente.

<CodeExample
  examples={{
    javascript: `<template>
  <div>

        {{ episode }}
      </div>
    </div>

    <!-- Componente AlcPagination -->
    <AlcPagination

      :total-pages="totalPages"
