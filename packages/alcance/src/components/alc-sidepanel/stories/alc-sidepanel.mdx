O Sidepanel foi projetado para exibir a navegação do sistema nas páginas que seguem o padrão do Alcance.

Ele apresenta seu conteúdo exibindo de forma conveniente, permitindo ao usuário mostrar ou esconder seu conteúdo conforme necessário.
Na interface visual, o Sidepanel inclui um botão de acionamento que o usuário pode usar para controlar a visibilidade do seu conteúdo.

Em dispositivos móveis, o Sidepanel é exibido na lateral direita, sobreposto ao conteúdo.
No modo desktop, o Sidepanel fica à esquerda do conteúdo da página, ocupando espaço de maneira eficiente e proporcionando fácil acesso às funcionalidades extras.

Embora tenha sido projetado para exibir a navegação do sistema, outros conteúdos podem ser inseridos no Sidepanel. Nesse caso, o desenvolvedor deve estar ciente de que sua interface pode não estar consistente com a de outras aplicações usando o Alcance. Portanto, o uso do Sidepanel para outros conteúdos deve ser feito com bastante critério.

## Estados do Sidepanel
O sidepanel precisa ter seu estado (aberto ou fechado) preservado enquanto o usuário navega pela aplicação. Ou seja, se o usuário fechou o sidepanel, ele tem que permanecer fechado enquanto o usuário não o abra novamente, independentemente das ações realizadas na aplicação.

A responsabilidade por manter o estado é da aplicação. Para isso, você poderá utilizar o `sessionStorage`, por exemplo. Caso sua aplicação utilize outros métodos para manipular o estado, fique livre para utilizá-lo.

Abaixo você encontra um exemplo de uso do `sessionStorage`:

<CodeExample type="js">
{`document.querySelector('alc-sidepanel').addEventListener('alc-state-request', e => {
  console.log('O estado foi requisitado');
    e.detail.state = JSON.parse(sessionStorage.getItem('app-sidepanel'));
});

document.querySelector('alc-sidepanel').addEventListener('alc-state-change', e => {
  console.log('O estado foi modificado:', e.detail.state);
    sessionStorage.setItem('app-sidepanel', JSON.stringify(e.detail.state) );
});`}
</CodeExample>
