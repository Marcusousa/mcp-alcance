## Input obrigatório
Adicione a propriedade `required="true"` no component alc-field.

Essa propriedade é apenas indicação visual, o tratamento deve ser feito pela aplicação.

## Input com texto de ajuda

## Input com error
Adicione a propriedade `error-msg="mensagem de erro"` no component alc-field.

Adicione essa propriedade apenas quando você quer ter o estado de erro no input. Para voltar ao estado padrão é so remover a propriedade.

## Personalização dos labels

O componente permite personalizar o label ao utilizar o `slot="label"` e adicionar
classes adicionais para a personalização.

### Formulário inline
No exemplo abaixo, utilizamos `alc-field` personalizado para que fique alinhado
em telas maiores e com a aparência padrão (label na parte superior do input) em telas pequenas.

Experimente fazer resize da tela para ver a mudança do field personalizado:

  <div>
    <alc-field :label="emailLabel" :required="true" :error-msg="emailError">
      <input type="email" v-model="email" name="email" id="id-para-email" />
    </alc-field>

    <alc-field>
      <!-- Usando o slot 'label' para personalizar o label -->
      <label slot="label" for="id-para-mensagem">Mensagem Personalizada</label>
      <textarea v-model="message" name="mensagem" id="id-para-mensagem"></textarea>
    </alc-field>

    <button class="alc-button" @click="sendMessage">Enviar Mensagem</button>
  </div>
</template>

<script lang="ts">
import { defineComponent, ref } from 'vue';

export default defineComponent({
  name: 'FieldExampleTS',
  setup() {
    const email = ref('');
    const message = ref('');
    const emailLabel = ref('E-mail');
    const emailError = ref('');

    const sendMessage = () => {
      if (email.value.trim() === '') {
        emailError.value = 'O campo e-mail é obrigatório.';
      } else if (!validateEmail(email.value)) {
        emailError.value = 'Por favor, insira um e-mail válido.';
      } else {
        emailError.value = '';
        // Processar a mensagem
        alert('Mensagem enviada com sucesso!');
      }
    };

    const validateEmail = (email: string) => {
      const re = /\S+@\S+\.\S+/;
      return re.test(email);
    };

    return {
      email,
      message,
      emailLabel,
      emailError,
      sendMessage,
    };
  },
});
</script>`
