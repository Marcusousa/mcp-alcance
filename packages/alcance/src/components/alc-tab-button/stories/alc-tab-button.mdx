# {Stories.default.name}

O componente `alc-tab-button` é utilizado para criar os botões que permitem alternar entre as abas dentro de um componente `alc-tabs`.

<Unstyled>
    <alc-alert dismissible="false">
    **Importante**: Assim como o `alc-tab`, o `alc-tab-button` **não funciona isoladamente**. Ele deve ser utilizado dentro de um componente `alc-tabs` e associado a uma aba específica através da propriedade `tab`.
    </alc-alert>
</Unstyled>

## Exemplo

Aqui está um exemplo de como o `alc-tab-button` deve ser utilizado em conjunto com os componentes `alc-tabs` e `alc-tab` para criar uma interface de abas funcional:

</alc-tabs>`}
