# {Stories.default.name}
Environment Label é um rótulo para identificar o ambiente em que se encontra o sistema com o qual o usuário está interagindo.

## Tipos de ambientes
São cinco os ambientes reconhecidos:

- prototype (Protótipo)
- development (Desenvolvimento)
- testing (Teste)
- homologation (Homologação)
- production (Produção)

No caso do `ambiente de Produção`, não será mostrada nenhuma marca visível para o usuário.

<alc-alert dismissible="false" type="warning">Se o valor informado for inválido, ou não for informado nenhum valor, o ambiente será identificado, para o usuário, como **Não reconhecido**.</alc-alert>
