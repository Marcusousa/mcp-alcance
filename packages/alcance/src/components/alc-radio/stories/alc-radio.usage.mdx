# Exemplos de {Stories.default.name}

## Básico
Há duas maneiras de criar o componente o radio: adicionando elemento label com slot nomeado ou adicionando a propriedade label no componente.

### Com propriedade label
<Canvas of={Stories.Basico} sourceState="shown" />
<Controls of={Stories.Basico} />

### Com slot label
<Canvas of={Stories.BasicoComSlot} sourceState="shown" />
<Controls of={Stories.BasicoComSlot} />

## Radio com texto de ajuda
Adicione a propriedade `hint="mensagem de ajuda"` no component alc-radio.

<Canvas of={Stories.TextoAjuda} sourceState="shown" />
<Controls of={Stories.TextoAjuda} />

## Radio com erro
Adicione a propriedade `error-msg="mensagem de erro"` no component alc-radio.

Adicione essa propriedade apenas quando você quer ter o estado de erro no radio. Para voltar ao estado padrão é so remover a propriedade.

<Canvas of={Stories.Erro} sourceState="shown" />
<Controls of={Stories.Erro} />

## Radio desabilitado
Adicione a propriedade `disabled` no input dentro do alc-radio.

<Canvas of={Stories.Desabilitado} sourceState="shown" />
<Controls of={Stories.Desabilitado} />

### Uso no Vue

<CodeExample 
  examples={{
    javascript: `<template>
  <div>
    <h2>Escolha seu personagem favorito</h2>
    <form>
      <alc-radio label="Lion-O" hint="O líder dos ThunderCats" error-msg="">
        <!-- Slot default para o input radio -->
        <input type="radio" name="personagem" value="lion-o" v-model="selectedCharacter" />
      </alc-radio>

      <alc-radio label="Cheetara" hint="A integrante mais rápida do grupo" error-msg="">
        <input type="radio" name="personagem" value="cheetara" v-model="selectedCharacter" />
      </alc-radio>

      <alc-radio hint="Escolha Snarf se quiser humor e companheirismo." error-msg="">
        <!-- Usando o slot label -->
        <span slot="label">Snarf</span>
        <input type="radio" name="personagem" value="snarf" v-model="selectedCharacter" />
      </alc-radio>

      <!-- Botão para confirmar seleção -->
      <button class="alc-button" type="button" @click="confirmSelection">
        Confirmar
      </button>
    </form>
  </div>
</template>

<script>
export default {
  name: 'RadioExample',
  data() {
    return {
      selectedCharacter: '',
    };
  },
  methods: {
    confirmSelection() {
      if (!this.selectedCharacter) {
        alert('Por favor, selecione um personagem.');
      } else {
        alert('Você selecionou: ' + this.selectedCharacter);
      }
    },
  },
};
</script>`,
