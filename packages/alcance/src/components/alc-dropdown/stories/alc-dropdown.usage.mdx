## Disparador com rótulo não visível

Apesar de não estar visível, o rótulo deve ser definido e é necessário.

<ul className="list-disc list-inside">
  <li>O rótulo do botão deve ser colocado no atributo label de `alc-icon`.</li>

## Fechamento automático

Tipicamente, usando um `menu` dentro do `dropdown`, deve-se configurar `hide-on="alc-select"` para que ele seja fechado quando o usuário selecionar uma opção do `menu`, conforme mostra este exemplo.

  <div>
    <alc-dropdown ref="dropdown" :open="isOpen" @alc-show="onShow" @alc-hide="onHide">
      <button slot="trigger" class="alc-button alc-button--secondary" @click="toggleDropdown">
        <alc-icon name="three-dots-vertical" label="Ações..."></alc-icon>
      </button>
      <alc-menu>
        <alc-menu-item value="excluir">Excluir</alc-menu-item>

export default {
  name: 'DropdownExample',

      this.isOpen = !this.isOpen;
    },
    onShow() {
      console.log('Dropdown vai abrir');

      console.log('Dropdown vai fechar');
