O componente `header` deve ser utilizado em todas as páginas do sistema. Contém os elementos que
naturalmente se repetem em todas as páginas, como a identificação do ambiente, o nome do sistema etc.

## Atributos `name` e `description`

O atributo `name` é obrigatório, e `description` é opcional.

Há três formas principais de utilização desses atributos, descritas abaixo.

Para outros casos diferentes desses indicados, deve ser avaliada a melhor forma de
utilização dos atributos, considerando sempre `name` como uma informação principal e
`description` como um complemento.

### 1. Apenas nome, sem descrição.

Para sistemas que não têm sigla e não precisam de descrição,
utilize apenas o atributo `name`.

Por exemplo: `name="Sistema de Delegações"`.

### 2. Sigla (ou nome curto) e nome por extenso

Para sistemas que possuem sigla (ou nome curto) e nome por extenso,
utilize `name` para a sigla e `description` para o nome por extenso.

Por exemplo: `name="Sigmas"`, `description="Sistema de Gestão de Material e Serviço"`.

### 3. Nome e contexto ou módulo

Para sistemas que possuem nome e necessitam de um contexto,
ou indicação de nome de um módulo,
utilize `name` para o nome e `description` para o contexto ou módulo.

Por exemplo: `name="Infoleg"`, `description="Parlamentar"`.

## Versão do sistema

O atributo `version` serve para informar a versão do sistema.

Se for informado, o header incluirá um botão com o rótulo "Sobre",
que abrirá uma janela modal com as informações do sistema, incluindo a versão.

O Alcance não define um formato específico para a versão.
Deve ser informado o identificador da versão, sem a palavra "versão" ou "v".

Por exemplo: `version="2.0.1"`, ou `version="2.0.1-beta+exp.5114f85"`.

O atributo `version` é opcional.
