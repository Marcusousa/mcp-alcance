# Design de {Stories.default.name}

## Anatomia

<img src='./static/images/header/anatomia-header.svg' alt="Anatomia do header" style={{margin: "1.5rem 0"}}/>

<span style={{color: "#168092"}}>**1  - Logo Câmara dos Deputados:**</span>

Deverá ser aplicado de forma obrigatória em todos os sistemas, mantendo o tamanho **36x36px** para os breakpoints inferiores e **40x40px** a partir do breakpoint 992.

<span style={{color: "#168092"}}>**2 - Identificação do Sistema | Obrigatório:**</span>

Destinado para identificação do sistema, pode ser o nome do sistema ou sigla. 

<span style={{color: "#168092"}}>**3 - Descrição do Sistema | Opcional:**</span>

Descrição servem para reforçar a identificação de uma sigla (escrita por extenso) associada ao título do sistema. 

<span style={{color: "#168092"}}>**4 - Área de funcionalidades:**</span>

São itens opcionais/ personalizáveis e devem ser utilizados quando houver necessidades específicas em cada sistema.

<span style={{color: "#168092"}}>**5 - Botão de funcionalidade:**</span>

São links opcionais de apoio, usados apenas quando relevantes ao contexto do sistema ou usuário

<span style={{color: "#168092"}}>**6 - Tag para notificação do header:**</span>

Item dinâmico para notificações.

<span style={{color: "#168092"}}>**7 - Separador:**</span>

Utilizado para separar a área de links funcionais da área de  identificação do usuário

<span style={{color: "#168092"}}>**8 - Identificação do usuário (nome):**</span>

Informação com o nome e ponto do usuário logado

<span style={{color: "#168092"}}>**9 - Identificação do usuário (avatar):**</span>

Informação com imagem/foto do usuário logado

<span style={{color: "#168092"}}>**10 - Identificação do usuário (cargo):**</span>

Informação com o nome e ponto do usuário logado

<span style={{color: "#168092"}}>**11 - Área para identificação do usuário:**</span>

Área destinada ao detalhamento do usuário logado, menu de ferramentas e autenticador.

<span style={{color: "#168092"}}>**12 - Menu do usuário (dropdown):**</span>

A lista dropdown é utilizada na área para Links e para Funcionalidades.
