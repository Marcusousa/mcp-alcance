# {Stories.default.name}

Os ícones de Alcance utilizam a biblioteca <a href="https://icons.getbootstrap.com/" class="alc-link">Boostrap Icons</a> sempre em sua última versão. 
Entretanto, a utilização desse componente, diferente dos outros componentes do Alcance, depende que a biblioteca dos ícones esteja na pasta pública do seu projeto. 
Siga a instalação abaixo para que os ícones funcionem corretamente em sua aplicação.

## Instalação
É necessário copiar a pasta `node_modules/alcance/dist/assets` para a pasta que serve arquivos estáticos em seu projeto.

É importante que `icons` continue existindo. Por exemplo: `<meu-projeto>/<pasta-de-arquivos-estaticos>/assets/icons`.

Você pode usar um simples script, conforme o exemplo abaixo, para que os ícones sejam copiados para a pasta pública do seu projeto:

<CodeExample type="js">
{`var fs = require('fs');
var fse = require('fs-extra');

// Se estiver usando o pacote alcance
var sourceDir = './node_modules/alcance/dist/assets';
// Se estiver usando o pacote alcance-vue-library
// var sourceDir = './node_modules/alcance-vue-library/node_modules/alcance/dist/assets';

var destDir = './public/assets';


// se a pasta não existir crie-a
if (!fs.existsSync(destDir)){
    fs.mkdirSync(destDir, { recursive: true });
}

// copiar o conteúdo do diretório, incluindo subpastas
fse.copy(sourceDir, destDir, function (err) {
  if (err) {
    console.error(err);
  } else {
    console.log("Assets copiados!");
  }
});`}
</CodeExample>

Informe ao Alcance qual é sua pasta de assets, exemplo:

<CodeExample type="js">
{`const resourcesUrl = \`\${new URL(window.location).origin}/alcance/static\`;

applyPolyfills().then(() => {
    defineCustomElements(window, {
    resourcesUrl: resourcesUrl
    });
});`}
</CodeExample>
