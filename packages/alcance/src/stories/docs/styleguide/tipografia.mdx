## Tipo de fonte: Roboto
O Alcance utiliza a fonte Roboto, projetada com diferentes escalas e pesos para facilitar a criação de hierarquias visuais bem definidas.
Ao final da documentação, você verá as instruções para instalar o pacote da fonte Roboto.

## Cores de texto

Os textos estáticos, como títulos, parágrafos e conteúdo de tabelas, devem seguir as cores estabelecidas pelos <a href="./?path=/docs/estilos-tokens--documentação" class="alc-link">tokens de cor de texto</a>, garantindo uniformidade visual e conformidade com requisitos de acessibilidade.

Textos coloridos devem ser aplicadas apenas em elementos interativos, como <a href="./?path=/docs/estilos-link--documentação" class="alc-link">links</a> e <a href="./?path=/docs/estilos-botões--documentação" class="alc-link">botões</a>, conforme descrito na documentação. Isso garante consistência visual e facilita a identificação desses elementos pelo usuário.

As cores da marca, como os tons de verde e azul usados no header, não devem ser aplicadas em textos.

## Cabeçalhos
Use cabeçalhos (headings) para títulos de página ou subtítulos para introduzir conteúdo ou seções de informação.

Os cabeçalhos têm tamanhos que contrastam com o conteúdo, aumentam a hierarquia visual e ajudam os leitores a entender facilmente a estrutura do conteúdo.

### Definições visuais dos cabeçalhos
Cores de texto:
- Modo Light: #2E2E2E (gray-80)
- Modo Dark: #E6E6E6 (gray-10)

Espaçamentos verticais:
- Margem superior (margin-top): --alc-spacing-05 / 1rem / 16px
- Margem inferior (margin-bottom): --alc-spacing-03 / 0.5rem / 8px

Os headings possuem margens superior e inferior por padrão.
Essas margens devem ser mantidas quando o heading estrutura áreas de conteúdo, como seções de texto.
Quando o heading apenas rotula componentes (como cards, por exemplo), o espaçamento deve ser definido pelo próprio componente.
Nesses casos, as margens do heading podem ser redefinidas (utilizando os <a href="./?path=/docs/estilos-tokens--documentação" class="alc-link">tokens de espaçamentos</a>) ou removidas.

## Boas Práticas
- O cabeçalho de nível 1 (`<h1>`) é o título principal da página e deve ser o primeiro elemento do conteúdo principal, identificando claramente o contexto da página atual.
- Use apenas um `<h1>` por página.
- Cabeçalhos devem ser usados para introduzir seções de conteúdo. Não utilize negrito ou tamanho de fonte para simular títulos, pois os cabeçalhos têm significado semântico e impacto direto na acessibilidade.
- O nível do cabeçalho deve refletir a hierarquia do conteúdo, não a aparência visual (`<h2>` para seções, `<h3>` para subseções, e assim por diante).
- Os cabeçalhos (`<h1>` a `<h6>`) devem seguir ordem sequencial, sem pular níveis, garantindo uma estrutura lógica e navegável.
- Os estilos de cabeçalhos são predefinidos. Ajustes visuais devem usar apenas <a href="./?path=/docs/estilos-tokens--documentação" class="alc-link">tokens</a> de texto específicos para cor, tamanho e line-height, sem alterar a semântica.

### Script de instalação
Caso você queira automatizar essa instalação, fornecemos um script simples que instala as fontes nos ***diretórios comuns ao Vue, React e Angular***. Caso seu projeto esteja configurado em outros diretórios,
ajuste o script de acordo com sua necessidade.

<CodeExample type="js">
{`const https = require('https');
const fs = require('fs');
const extract = require('extract-zip');

const fontUrl = 'https://fonts.google.com/download?family=Roboto';
const destination = './Roboto.zip';

const file = fs.createWriteStream(destination);
const request = https.get(fontUrl, function(response) {
  response.pipe(file);
  file.on('finish', function() {
    file.close(() => {
      console.log('Fonte baixada.');

      // Extrai as fontes
      extract(destination, { dir: './public/assets/fonts' }, function (err) {
        if (err) {
          console.log('Ocorreu um erro ao extrair o zip da fonte.', err);
        } else {
          console.log('As fontes foram extraidas com sucesso.');
        }
      });
    });
  });
}).on('error', function(err) {
  fs.unlink(destination);
  console.error('Ocorreu um erro durante o download da fonte.', err);
});`}
</CodeExample>
