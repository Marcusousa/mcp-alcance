## Exemplo de código

### Botão primário

Use a classe `alc-button` para os botões. O uso de apenas essa classe cria um botão primário.

<Unstyled>
  <button className="alc-button">Salvar</button>
</Unstyled>

<CodeExample type="html">
{`<button class="alc-button">Salvar</button>`}
</CodeExample>

### Botão secundário

A classe `alc-button--secondary` deve ser usada em um botão secundário.

<Unstyled>
  <button className="alc-button alc-button--secondary">Salvar</button>
</Unstyled>

<CodeExample type="html">
{`<button class="alc-button alc-button--secondary">Salvar</button>`}
</CodeExample>

### Desabilitados

Adicione o atributo `disabled` nos botões.

<Unstyled>
  <button className="alc-button" disabled>Salvar</button>
</Unstyled>

<CodeExample type="html">
{`<button class="alc-button" disabled>Salvar</button>`}
</CodeExample>

## Quando usar

Os botões são elementos clicáveis usados para acionar ações. Eles comunicam chamadas à ação para o usuário e permitem que ele interaja com as páginas de diversas maneiras. Os rótulos dos botões expressam qual ação ocorrerá quando o usuário interagir com eles.

## Quando não usar

Não utilize botões como elementos de navegação. Em vez disso, use links quando a ação desejada for levar o usuário a uma nova página.

Consulte a <a class="alc-link" href="./?path=/docs/estilos-link--documentação">documentação de links</a> para mais informações.

## Tamanho

O botão deve ter altura total de `40px`, considerando bordas e espaçamentos. A largura será ajustada automaticamente conforme o tamanho do texto do rótulo.

## Espaçamentos entre botões

Havendo dois ou mais botões em um conjunto, o espaçamento visual entre eles deve obedecer ao tamanho `--alc-spacing-03` (0.5rem / 8px).

<ImageCard>
  <img src='./static/images/button/button-espacamento.svg' alt="Demonstração do espaçamento entre botões" />
</ImageCard>

**A aplicação é responsável por garantir esse espaçamento.**
Nos exemplos a seguir, isso foi feito utilizando `flexbox` no contêiner dos botões. A classe CSS usada nos exemplos é a seguinte:

{`${css}`}
</CodeExample>

## Boas práticas

- O botão principal deve sempre vir antes do secundário — à esquerda quando estiverem lado a lado e acima quando estiverem dispostos na vertical.
- Em páginas com vários botões, é indicado que haja apenas um botão principal, representando a ação mais importante da página. Os demais devem ser configurados como secundários.
- Os textos dos botões devem explicar claramente qual ação será realizada. Utilize verbo + objeto: “Salvar alterações”, “Excluir conta”, etc.
- Use rótulos consistentes para ações opostas, como: “Salvar” / “Cancelar”, “Ativar” / “Desativar”, “Aceitar” / “Recusar”.
- Use letra maiúscula apenas na primeira palavra do rótulo do botão. Use: "Salvar rascunho". Evite: “SALVAR RASCUNHO”, “Salvar Rascunho”, “salvar rascunho”.
- Ações que possam causar perda de dados ou mudanças irreversíveis devem ter textos claros e exigir confirmação adicional quando necessário.
