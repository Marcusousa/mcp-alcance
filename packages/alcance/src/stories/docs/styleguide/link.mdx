# Link

<IntroDoc>
  Um link é um elemento que permite que os usuários naveguem entre diferentes páginas da web ou para outras áreas dentro da mesma página.
</IntroDoc>

## Quando usar 
Use links quando você quiser que os usuários:
- Naveguem para uma página diferente dentro da aplicação.
- Naveguem para um site completamente diferente.
- Saltem para um elemento na mesma página.
- Acessem um e-mail ou número de telefone via link.

## Quando não usar
Não use links para **alterar dados** ou manipular como eles são exibidos, **mudar um estado** ou **disparar uma ação**.
Em vez disso, use botões para guiar os usuários a ações específicas.

Consulte a <a class="alc-link" href="./?path=/docs/estilos-botões--documentação">documentação de botão</a> para mais informações.

## Tamanho

Considere links como texto para definir o tamanho da fonte e altura da linha, conforme definido na <a class="alc-link" href="./?path=/docs/estilos-tokens--documentação#escala-de-texto">documentação de tokens de escala de texto</a>.

Links contidos no corpo do texto devem sempre seguir o tamanho do texto ao seu redor.

## Boas práticas

- Use texto de link distintivo e significativo.
- Garanta que os links reflitam com precisão o conteúdo que os usuários encontrarão no destino do link.
- Evite usar textos genéricos como “clique aqui” ou “saiba mais”;
- Evite usar o mesmo texto de link para destinos diferentes na mesma página e tente diferenciar os links usando texto exclusivo para cada um.
- Certifique‑se de que os links sejam compreensíveis, mas não excessivamente longos, especialmente se quebrarem em várias linhas.


Tenha atenção ao posicionamento e à linguagem dos links e crie experiências inclusivas para usuários que navegam com leitores de tela. Leitores de tela extraem uma lista de links — somente o texto do link, sem incluir o contexto — para determinar o conteúdo da página.
Pessoas que usam leitores de tela podem alternar entre links sem obter o texto entre eles, por isso é importante seguir o guia de boas práticas

## Acessibilidade

### Interação pelo teclado

`Enter` - Executa o link e move o foco para o destino do link.
