<h1> Estilos </h1>


Para garantir a consistência visual dos em elementos que não são fornecidos pela biblioteca Alcance em formato de componentes, são disponibilizadas classes CSS específicas.

Diversas dessas classes seguem o padrão de nomenclatura **.alc-** como indicativo de pertencimento à biblioteca Alcance. 
Entretanto, é importante notar que nem todas as classes adotam esse prefixo, como é o caso da grid que utiliza a grid do Bootstrap.

Para elementos que não fazem parte dos componentes do Alcance, é recomendado o uso adequado das classes CSS fornecidas pela biblioteca. 
Essa prática visa garantir uma experiência de usuário consistente e alinhada ao design do sistema.
