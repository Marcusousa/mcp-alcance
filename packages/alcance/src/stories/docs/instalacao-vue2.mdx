## Configuração

Copie a pasta `assets` do Alcance para pasta `public/assets/`, conforme o *exemplo* abaixo:

<CodeExample type="js" title="scripts/process.js">
{`var fs = require('fs');
var fse = require('fs-extra');

var sourceDir = './node_modules/alcance/dist/assets';
var destDir = './public/assets';


// se a pasta não existir crie-a
if (!fs.existsSync(destDir)){
    fs.mkdirSync(destDir, { recursive: true });
}

// copiar o conteúdo do diretório, incluindo subpastas
fse.copy(sourceDir, destDir, function (err) {
  if (err) {
    console.error(err);
  } else {
    console.log("Assets copiados!");
  }
});`}
</CodeExample>

Adicione as seguintes linhas no arquivo `main.js` localizado na pasta `src` do seu projeto:

<CodeExample type="js" title="src/main.js">
{`import Vue from 'vue'
import App from './App.vue'
import { applyPolyfills, defineCustomElements } from 'alcance/loader';
import "alcance/dist/alcance/alcance.css";

// Configure o diretório onde ficam os assets de seu projeto.
// Isso é especialmente importante para componentes do Alcance que utilizam esse
// recurso, como o <alc-icon>
const resourcesUrl = \`\${new URL(window.location).origin}/assets/\`;

applyPolyfills().then(() => {
  defineCustomElements(window, {
    resourcesUrl: resourcesUrl
  });
});
// Informa ao Vue para ignorar os custom elements iniciados com *alc*
Vue.config.ignoredElements = [/^alc-/];

new Vue({
    render: h => h(App),
}).$mount('#app')`}
</CodeExample>
Essa configuração corresponde a importação do loader do Alcance, do arquivo de estilos e da definição para a pasta de resources que o Alcance irá utilizar.
