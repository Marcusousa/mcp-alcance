## Instalando o Alcance

### Instalação expressa (usando NodeJS)
Utilize a instalação expressa para instalar rapidamente o pacote Alcance e obter a cópia dos assets (ícones, imagens, fontes) para seu projeto:

<CodeExample language="shell">
{`npx alcance-init`}
</CodeExample>
ou

<TabsState
  initial="npmins">
    <div id="npmins" title="NPM">
        <div>
            <CodeExample language="shell">
            {`npm i -g alcance-init

alcance`}
            </CodeExample>
        </div>
    </div>
    <div id="yarnins" title="Yarn">
        <div>
            <CodeExample language="shell">
            {`yarn global add alcance-init

alcance`}
            </CodeExample>
        </div>
    </div>
</TabsState>

A instalação expressa resume rapidamente todo o processo de instalação do Alcance e dos pacotes de ícones e fotes necessários para funcionamento correto do Alcance.

<Unstyled>
<alc-alert dismissible="false">

Note que essa instalação ainda não substitui a configuração necessária em qualquer framework em que for utilizado.

</alc-alert>
</Unstyled>

### Instalação manual (sem NodeJS)
Caso seu projeto não utilize o NodeJS, é necessário baixar e extrair manualmente os arquivos do Alcance.

Você poderá encontrar os arquivos em <a href="./?path=/docs/instalação-histórico-de-versões--documentação" className="alc-link">Histórico do Alcance</a>.

Após o download, descompacte o arquivo e mova a pasta `package` para uma pasta onde os arquivos possam ser distribuídos na rede, exemplo: pasta `public` ou pasta `static` a depender da estrutura do seu projeto.

Renomeie a pasta `package` para `alcance`.

## Copiando os assets

É necessário copiar a pasta `node_modules/alcance/dist/assets` para a pasta que serve arquivos estáticos em seu projeto.

Você pode usar um simples script, conforme o exemplo abaixo, para que os assets sejam copiados para a pasta pública do seu projeto:

<CodeExample
  examples={{
    javascript: `var fs = require('fs');
var fse = require('fs-extra');

// Se estiver usando o pacote alcance
var sourceDir = './node_modules/alcance/dist/assets';
// Se estiver usando o pacote alcance-vue-library
// var sourceDir = './node_modules/alcance-vue-library/node_modules/alcance/dist/assets';

var destDir = './public/assets';

// se a pasta não existir crie-a
if (!fs.existsSync(destDir)){
    fs.mkdirSync(destDir, { recursive: true });
}

// copiar o conteúdo do diretório, incluindo subpastas
fse.copy(sourceDir, destDir, function (err) {
  if (err) {
    console.error(err);
  } else {
    console.log("Assets copiados!");
  }
});
`,
    typescript: `import * as fs from 'fs';
import * as fse from 'fs-extra';

// Se estiver usando o pacote alcance
const sourceDir = './node_modules/alcance/dist/assets';
// Se estiver usando o pacote alcance-vue-library
// const sourceDir = './node_modules/alcance-vue-library/node_modules/alcance/dist/assets';

const destDir = './public/assets';

// Se a pasta não existir, crie-a
if (!fs.existsSync(destDir)){
    fs.mkdirSync(destDir, { recursive: true });
}

// Copiar o conteúdo do diretório, incluindo subpastas
fse.copy(sourceDir, destDir, (err: Error) => {
  if (err) {
    console.error(err);
  } else {
    console.log("Assets copiados!");
  }
});
`,
  }}
/>
