Fácil de usar

O Alcance está sendo construído para ser utilizado de forma prática. Instale, configure e tenha à mão os recursos para oferecer uma boa experiência aos usuários.

Compatível

Nada de quebrar a cabeça para usar os componentes. O Alcance utiliza web components, pode ser usado em diversos frameworks de front-end e funciona nos navegadores modernos.

Moderno

Para o usuário, pensado para dispositivos móveis e com temas que respeitam suas preferências. Para o desenvolvedor, modular e extensível. O Alcance está a tom com as tecnologias atuais.
