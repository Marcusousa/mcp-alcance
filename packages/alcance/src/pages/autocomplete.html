Web Component - Autocomplete

Sugestões de funcionalidades

  1. Prop() label título do campo busca
  2. Prop() hint mensagem de ajuda para realizar a pesquisa
  3. Prop() placeholder mensagem inicial que aparece dentro do input
  4. Prop() required campo obrigatório
  5. Prop() data-url url do serviço que deseja utilizar
  6. ...Loading (resposta do serviço)
  7. Mensagem de serviço indisponível (resposta do serviço)
  8. Prop() display-keys parâmetros apresentados na lista
  9. Prop() list-direction tipo de visualização da lista
  10. Navegação por teclado (Setas, Esc e Enter)
  11. Scroll para visualização vertical
  12. Sincronização de item selecionado e scroll
  13. Limitador de itens da lista (Mensagem de ajuda)
  14. Requisição a partir de (2) caracteres
  15. Pesquisa com letra maiúscula, minúscula e acento gráfico.
  16. Input disabled
  17. (InputValue) Valor selecionado
  18. Resultado não encontrado
  19. Map() antes da pesquisa no serviço (?)

Alterações de funcionalidades
